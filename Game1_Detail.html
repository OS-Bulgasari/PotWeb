01. ScriptableObject 대화 시스템

데이터와 로직의 분리를 위해 ScriptableObject를 사용하여 NPC별 대화 데이터를 관리했습니다.

// 예시 코드: 대화 데이터 구조체
[CreateAssetMenu]
public class DialogueData : ScriptableObject {
    public string npcName;
    public List lines;
}
